Web Application ตัวอย่างสำหรับโปรเจกต์กลุ่ม ใช้ HTML, CSS, JavaScript, Fetch API, Node.js, Express และ MongoDB

## ฟังก์ชัน
- สมัครสมาชิกและเข้าสู่ระบบ (Resident/Admin)
- ผู้พักแจ้งซ่อม ระบุห้อง ประเภท รายละเอียด ความเร่งด่วน และแนบรูปภาพ
- ค้นหาและกรองรายการแจ้งซ่อม
- ผู้พักเห็นเฉพาะรายการของตนเอง ส่วนผู้ดูแลเห็นรายการทั้งหมด
- ผู้ดูแลอัปเดตสถานะ มอบหมายช่าง และบันทึกหมายเหตุการซ่อม
- เก็บประวัติการเปลี่ยนสถานะ
- Dashboard สรุปสถิติและกราฟตามประเภท/สถานะ
- API ตรวจสิทธิ์ด้วย JWT และจำกัดการเรียก endpoint เข้าสู่ระบบ

## สิ่งที่ต้องติดตั้ง
- Node.js 18 ขึ้นไป
- MongoDB ในเครื่อง หรือ MongoDB Atlas

## วิธีเริ่มต้น
1. เปิด Terminal ในโฟลเดอร์ `DormFix`
2. ติดตั้งแพ็กเกจ:
   ```bash
   npm install
   ```
3. คัดลอก `.env.example` เป็น `.env` แล้วตั้ง `MONGODB_URI` และเปลี่ยน `JWT_SECRET` เป็นค่าสุ่มที่ยาว
4. ตรวจให้ MongoDB ทำงานอยู่
5. (ทางเลือก) สร้างบัญชีและข้อมูลตัวอย่าง:
   ```bash
   npm run seed
   ```
6. เริ่มระบบ:
   ```bash
   npm start
   ```
7. เปิด http://localhost:3000

## บัญชีทดลอง (หลังรัน `npm run seed`)
- ผู้ดูแล: `admin@dormfix.local` / `DormFix123!`
- ผู้พัก: `resident@dormfix.local` / `DormFix123!`

เปลี่ยนรหัสผ่านและ secret ก่อนใช้จริง ห้ามใช้บัญชีตัวอย่างกับข้อมูลจริง

## API หลัก
- `POST /api/auth/register` สมัครบัญชีผู้พัก
- `POST /api/auth/login` เข้าสู่ระบบ
- `GET /api/auth/me` ข้อมูลผู้ใช้ปัจจุบัน
- `GET /api/repairs` รายการแจ้งซ่อม (ผู้พักเห็นเฉพาะของตน)
- `POST /api/repairs` สร้างรายการ (multipart/form-data)
- `GET /api/repairs/:id` ดูรายละเอียดและประวัติ
- `PATCH /api/repairs/:id/status` เปลี่ยนสถานะ (Admin เท่านั้น)
- `DELETE /api/repairs/:id` ลบรายการตามสิทธิ์
- `GET /api/health` ตรวจสถานะเซิร์ฟเวอร์/ฐานข้อมูล

## หมายเหตุ
- รูปภาพรองรับ JPEG, PNG, WebP ขนาดไม่เกิน 4 MB และเก็บไว้ในโฟลเดอร์ `uploads` สำหรับการสาธิตในเครื่อง
- การอัปโหลดในระบบใช้งานจริงควรย้ายไป object storage และเพิ่มการตรวจสอบไฟล์/นโยบายสำรองข้อมูล
